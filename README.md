# C++ Programming Fundamentals Labs (AzTU)

Bu repozitoriya **Azərbaycan Texniki Universitetinin (AzTU)** "Proqramlaşdırmanın əsasları" fənni üzrə yerinə yetirilmiş laboratoriya tapşırıqlarını və C++ həllərini ehtiva edir.

## 📚 Laboratoriya İşlərinin Siyahısı

| Lab | Mövzu | Əhatə olunan mövzular |
| :--- | :--- | :--- |
| **Lab 01** | Şərt operatorları və sadə hesablamalar | `if-else`, arifmetik operatorlar (`/`, `%`), sintaksis |
| **Lab 02** | Dövrlər və `enum` tipləri | `for`, `while`, `enum`, kvadrat tənlik |
| **Lab 03** | Ədədlər üzərində alqoritmlər | Palindrom, Armstrong ədədləri, ƏBOB/ƏKOB, `switch` |
| **Lab 04** | Birölçülü massivlər və funksiyalar | Massiv elementlərinin axtarışı, silinməsi və dəyişdirilməsi |
| **Lab 05** | Çoxölçülü massivlər (Matrislər) | Kvadrat matris, diaqonal elementlər, siklik sürüşdürmə |
| **Lab 06** | Funksiyalar və Rekursiya | Sadə/mürəkkəb ədədlər, rekursiv faktorial və qüvvət, Heron düsturu |
| **Lab 07** | Sətirlər (`std::string`) üzərində iş | Sətirlərin emalı, prefiks/suffiks, simvol sayımı |
| **Lab 08** | Laboratoriya işi 08 | C++ praktiki tapşırıqlar |
| **Lab 09** | Fayllar və sətirlərlə iş | `ifstream`, `ofstream`, fayl oxuma və yazma əməliyyatları |

## 🛠️ İstifadə Olunan Texnologiyalar
